## Быстрые сценарии

Выбери задачу и пройди по указанным пунктам. Например, **12 → 6 → 2** означает: главное меню → управление NFQWS2 → настройки DNS → добавить DoH.

| Хочу… | Куда перейти | Что получится |
| --- | --- | --- |
| Установить NFQWS2 | **4** | Пакет NFQWS2 и его штатные файлы |
| Сразу настроить XKeen с Mihomo | **7** | Ядро, геофайлы, расписание обновления и автозагрузка |
| Применить готовую стратегию | **12 → 1** | Проверенная конфигурация с копией предыдущей |
| Подготовить все fake-пакеты | **12 → 2** | Каталог blobs NFQWS2 |
| Проверить зависимости действующего конфига | **12 → 3** | Проверка blobs и списков текущей стратегии |
| Добавить защищённый DNS | **12 → 6 → 1 / 2** | Общий DoT или DoH либо сервер для указанного домена |
| Направить отдельный домен к другому DNS | **12 → 6 → 3** | Готовая доменная привязка; для собственного домена — добавление DoT/DoH с заполнением поля домена |
| Попробовать исправить обрыв голоса Discord | **12 → 9 → 2** или **S → 3 → 2** | Правила обработки UDP-сессии в NFQWS2 |
| Сменить зеркало Entware | **22 → 3** | Новый источник пакетов и копия прежнего opkg.conf |
| Сохранить opkg.conf | **22 → 4 → 1** | Отдельная резервная копия |
| Восстановить opkg.conf | **22 → 4 → 2** | Последняя копия, созданная Xmenu |
| Обновить списки доступных пакетов | **22 → 5** | Новые индексы Entware |
| Обновить Xmenu | **21** | Проверка загрузки и замена скрипта с резервной копией |
| Удалить отдельный компонент | **19** | Список действий удаления с подтверждениями |

> [!TIP]
> Перед экспериментами со стратегиями создай архив командой `xmenu backup`. Копии `opkg.conf` управляются отдельно через **22 → 4**.
