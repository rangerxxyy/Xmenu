[◆ Wiki Xmenu](../WIKI.md) · [Читать целиком](Full-guide.md) · [README](../../README.md)

## Пути и файлы

| Путь | Содержимое |
| --- | --- |
| `/opt/bin/xmenu` | Установленное меню |
| `/opt/etc/xmenu/` | Настройки, кэши и служебные данные |
| `/opt/etc/xmenu/backups/` | Копии конфигураций и архивы |
| `/opt/etc/xmenu/language` | Выбранный язык |
| `/opt/etc/opkg.conf` | Источники Entware |
| `/opt/etc/nfqws/nfqws.conf` | Конфигурация NFQWS v1 |
| `/opt/etc/nfqws2/nfqws2.conf` | Конфигурация NFQWS2 |
| `/opt/etc/nfqws2/blobs/` | Ресурсы NFQWS2 |
| `/opt/etc/nfqws2-fullsession/fullsession.conf` | Порты Discord Fix |
| `/opt/etc/init.d/S52xmenu-discord-fullsession` | Восстановление правил Discord при загрузке |
| `/opt/etc/ndm/netfilter.d/101-xmenu-discord-fullsession.sh` | Восстановление правил после изменений firewall |
