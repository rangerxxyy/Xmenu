# ◆ Что умеет Xmenu

[◆ Wiki Xmenu](../WIKI.md) · [Читать целиком](Full-guide.md) · [README](../../README.md)

| Раздел | Возможности |
| --- | --- |
| 📦 Компоненты | XKeen Stable, Xray, Mihomo, панели XKeen UI, NFQWS v1/v2 и веб-интерфейсы |
| 🧩 Стратегии | Каталог из 40 вариантов NFQWS2, контрольные суммы, кэш и резервное копирование |
| 🌐 DNS | Текущие DNS интернет-фильтров, DoT/DoH, привязки доменов и статические hosts |
| 🎙 Discord | Обработка голосовой UDP-сессии в NFQWS2, исключение из ускорения и интеграция с XKeen |
| 🛠 Обслуживание | Зеркала Entware, копии `opkg.conf`, Dropbear Fix, сжатие UPX и удаление компонентов |
| 🔎 Диагностика | Проверка сайта, DNS-серверов и доступности VPS, запуск DPI Detector |

Xmenu работает поверх Entware: выполняет пакетные команды, запускает установщики выбранных компонентов и управляет их конфигурациями. Основные действия доступны через меню и команды SSH.
