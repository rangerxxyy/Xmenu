# 🧰 Компоненты и профили

[◆ Wiki Xmenu](../WIKI.md) · [Читать целиком](Full-guide.md) · [README](../../README.md)

### Пункты 1–7: отдельные компоненты

| № | Компонент | Что выполняется |
| --- | --- | --- |
| 1 | **XKeen — Stable** | Загрузка и запуск установки стабильного XKeen. Канал установленного компонента проверяется отдельно от наличия файла. |
| 2 | **XKeen UI — zxc-rv** | Установка панели управления XKeen. При обнаружении существующей панели перед продолжением запрашивается подтверждение. |
| 3 | **XKeen UI — umarcheh001** | Загрузка архива панели, проверка путей и состава, сохранение существующей директории и запуск установщика. |
| 4 | **nfqws2** | Подключение репозитория пакета и установка либо обновление `nfqws2-keenetic`. |
| 5 | **nfqws v1** | Поэтапная установка / обновление: совместимость → зависимости → официальный репозиторий → пакет → конфиг и служба. При установленном nfqws2/tpws операция останавливается до изменений из-за конфликтов пакетов. |
| 6 | **nfqws-web-keenetic** | Установка веб-интерфейса для управления конфигурацией NFQWS. |
| 7 | **nfqws2-ui** | При установленной панели — запуск её команды обновления; при отсутствии — загрузка отдельного установщика панели. |

Загружаемые установщики проверяются на ожидаемое содержимое и shell-синтаксис, когда это предусмотрено соответствующей операцией. Их собственные диалоги, порты и адреса панелей выводятся при запуске.

### Пункты 8–11: готовые профили

| № | Профиль | Состав |
| --- | --- | --- |
| 8 | **XKeen Auto / Mihomo** | XKeen Stable, Mihomo, GeoIP/GeoIPSet, автозагрузка и ежедневное обновление геофайлов в 04:30 по времени роутера |
| 9 | **XKeen Auto / Xray** | Тот же профиль с ядром Xray |
| 10 | **Полный / Mihomo** | Профиль 8, панель XKeen UI, NFQWS2 и NFQWS Web |
| 11 | **Полный / Xray** | Профиль 9, панель XKeen UI, NFQWS2 и NFQWS Web |

Выбранное ядро устанавливается или обновляется. Если шаг полного профиля завершается ошибкой, последовательность останавливается с указанием компонента.
