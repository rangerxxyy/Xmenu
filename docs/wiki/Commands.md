# ⌨️ Команды SSH

[◆ Wiki Xmenu](../WIKI.md) · [Читать целиком](Full-guide.md) · [README](../../README.md)

| Команда | Назначение |
| --- | --- |
| `xmenu` | Главное меню |
| `xmenu status` | Устройство и установленные компоненты |
| `xmenu update-xmenu` | Обновить Xmenu |
| `xmenu install-nfqws` | Поэтапная установка / обновление NFQWS v1 |
| `xmenu site-check URL [URL…]` | Обычная и прямая проверка до пяти адресов |
| `xmenu site-check --direct URL` | Только принудительно напрямую через WAN |
| `xmenu dns-check` | Интерактивная проверка DNS-серверов |
| `xmenu server-check IP` | Проверка доступности VPS |
| `xmenu strategies` | Выбор стратегии |
| `xmenu sync` | Проверить ресурсы активного конфига |
| `xmenu install-blobs-nfqws2` | Загрузить каталог blobs NFQWS2 |
| `xmenu rkn-list` | Обновить rkn.list |
| `xmenu opkg-settings` | OPKG и зеркала Entware |
| `xmenu backup` | Создать архив конфигураций |
| `xmenu dpi-detector [аргументы]` | Запустить диагностику с передачей аргументов |

<details>
<summary><b>Команды установки компонентов</b></summary>

```sh
xmenu install-xkeen
xmenu install-xkeen-ui
xmenu install-xkeen-ui-umarcheh001
xmenu install-nfqws
xmenu install-nfqws2
xmenu install-nf-web
xmenu install-nf-web2
xmenu install-dpi-detector
xmenu install-tg-ws-proxy-rust
xmenu install-keenkit
xmenu install-awg-manager
xmenu install-all
```

Интерактивные установщики могут задавать дополнительные вопросы. Используй полноценную SSH-сессию.

</details>
